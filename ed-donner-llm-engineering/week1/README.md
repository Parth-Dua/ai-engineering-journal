# Week 1 — Frontier APIs & First LLM App

**Project:** AI Company Brochure Generator — scrapes a company website and produces formatted sales brochures using an LLM.

**What I learned:**
- Calling OpenAI, Anthropic, and Google APIs directly
- Running open-source models locally with Ollama (Llama 3.2, Phi-3)
- Prompt engineering basics — system vs user prompts, context windows
- Streaming responses and token/cost management
- Comparing Frontier vs open-source model outputs on the same task

**Notebooks:** `day1` → first local model with Ollama · `day2` → Frontier API calls · `day4` → brochure generator build · `day5` → multi-model comparison
